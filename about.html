THE MISSION

Why We Built Smart LT

A hackathon initiative to solve physical line break risks on low-voltage distribution lines before they cause wildfires, damage, or widespread blackout cascades.

The Grid Safety Problem

Low-tension (LT) overhead electrical lines are highly vulnerable to physical breakage from storms, fallen trees, and aging infrastructure. Conventional protection relays often fail to detect downed live wires quickly, creating severe electrocution hazards, property fires, and unmanaged outages.

Our Hackathon Solution

Smart LT combines continuous high-frequency signal sampling with edge ML pattern matching. Within 50 milliseconds of a break, the system pinpoints the broken line segment, trips automated sectionalizing switches, and alerts grid operators via a real-time web dashboard.

HACKATHON ARCHITECTURE

Core Technical Features

Key components developed for the hackathon MVP prototype.

01

High-Speed Signal Stream

Simulates 10kHz+ sampling of line voltage and current to detect transient impedance drops instantantly.

02

Sub-50ms Edge Inference

Lightweight neural net classifier designed for microcontrollers to distinguish true line breaks from normal load switching.

03

Visual Topology Engine

Interactive Canvas telemetry map displaying real-time power flow across monitored substation sections.

04

Live Fault Injection

Interactive 6-step simulator demonstrating real-time fault detection, isolation, and auto-restoration pipeline.

05

AI Grid Assistant

Built-in AI Assistant drawer for natural language grid diagnostics, fault troubleshooting, and demo controls.

06

Zero-Dependency Stack

Vanilla HTML5, Glassmorphism CSS, Canvas 2D graphics, and Lucide icons for ultra-fast, lightweight performance.

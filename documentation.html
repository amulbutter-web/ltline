Troubleshooting

Common issues and resolution procedures.

Check network connectivity. Verify edge node power and communication LEDs. If cellular, confirm signal strength.
Verify sensor calibration and connections. Check PT ratio configuration. Environmental factors may affect accuracy.
Confirm communication link status. Check event filter settings. Review edge node logs locally.

API Documentation

Smart LT provides a RESTful API and WebSocket interface for integration.

API Endpoints REST / WebSocket 
Base URL: https://api.smartlt.local/v1

GET  /status          — System overall status
GET  /sections         — All section data
GET  /sections/:id     — Specific section detail
GET  /events           — Event history (paginated)
WS   /ws/live          — Real-time data stream

Full OpenAPI/Swagger reference available upon system deployment.
